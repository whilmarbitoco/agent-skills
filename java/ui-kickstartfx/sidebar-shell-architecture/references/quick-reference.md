# Sidebar Shell — Quick Reference

| Concept | Convention |
|---|---|
| Shell control | Loaded once via `ShellView.fxml` |
| Content area | `StackPane` in `BorderPane.CENTER` |
| Route tracking | `ObjectProperty<Route>` bound to sidebar toggle |
| Collapse | Animated `TranslateX`, pseudo-class toggle |
| Topbar | Static — brand, search, user menu in shell |
